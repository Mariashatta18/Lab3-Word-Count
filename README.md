# Lab 3 – Word Count Analyzer

**Author:** Mariam Shatta

## Project Description
This project is a Python word frequency analyzer developed using Object-Oriented Programming (OOP). The program reads text files, processes their contents, and counts how many times each word appears.

## How the Program Works
The program uses a class called `WordAnalyzer` to organize the code and manage word counting.

1. Displays a menu with four books to choose from.
2. Opens the selected text file.
3. Converts the text to lowercase to count words consistently.
4. Removes punctuation and separates the text into individual words.
5. Uses a dictionary to store each word and its frequency.
6. Displays the results in alphabetical order.
7. Allows the user to return to the menu or exit the program.

## How to Run
1. Open the project in GitHub Codespaces or VS Code.
2. Open the terminal.
3. Run the following command:

   `python Lab10_mshatta-1.py`

4. Select a book by entering a number from 1 to 4.
5. Review the word frequency report.
6. Enter 5 to exit the program.
